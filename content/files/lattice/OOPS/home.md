# Object-Oriented Programming

This workspace introduces object-oriented programming concepts, design principles, design patterns, and the relationships between cohesion, coupling, and maintainable code. The focus is on using abstractions deliberately rather than treating classes and inheritance as goals by themselves.

## Suggested Path

1. Learn objects, classes, interfaces, encapsulation, inheritance, abstraction, and polymorphism.
2. Use cohesion and coupling to evaluate whether responsibilities are placed well.
3. Study SOLID principles and the Law of Demeter as design guidance.
4. Treat creational, structural, and behavioral patterns as named options—not mandatory templates.

## Design Questions

- What responsibility belongs to this object or module?
- Can the code change without forcing unrelated callers to change?
- Is inheritance expressing a genuine “is-a” relationship, or would composition be clearer?
- Does a pattern reduce complexity, or is it adding ceremony?

Examples may use different programming languages. Focus first on the design idea, then adapt the syntax to the language and runtime you are using.
