# Introduction to Japanese — N4

N4 extends the N5 foundation. The supplied workbook contains separate N4-labeled rows for kanji, nouns, verbs, katakana words, particles, adverbs, and both adjective types. Those rows are filtered into the N4 categories in this workspace.

## Study path

1. Keep hiragana and katakana automatic; N4 introduces no new alphabet. Review [N4 reading and kanji](/JapaneseN4-n4-reading-and-kanji).
2. Work through the [N4 grammar patterns](/JapaneseN4-n4-grammar-patterns), comparing each pattern with examples from a trusted reference.
3. Study N4 vocabulary by type and learn the N4 kanji in words, not in isolation.
4. Revisit N5 topics when a sentence depends on a basic form you have not mastered.

The grammar lesson is a curated starting list, not an official JLPT checklist. The workbook’s N4 labels are retained in the reference tables.
