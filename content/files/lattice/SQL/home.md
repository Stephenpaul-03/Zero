# SQL

This workspace covers SQL from querying and data definition through functions, transactions, optimization, normalization, and relational theory.

## Suggested Path

Learn commands, data types, constraints, filtering, grouping, sorting, joins, subqueries, and query execution order first. Then continue with functions, indexes, views, stored procedures, transactions, CTEs, optimization, and database theory.

## What to Practice

Write queries against small examples, inspect how joins affect row counts, verify assumptions with test data, and consider correctness, readability, indexes, and transaction behavior together.
