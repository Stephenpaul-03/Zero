# GPA Calculator — Local development

## Local development

Run these commands from the project repository. Commands listed here were inspected, not executed as part of writing this page.

~~~sh
npm install
npm run dev
npm run build
npm run preview
~~~

## Project notes

The preset format documented in the repository is index, semester, subjectcode, subjectname, credits, and grade. Credits and grades are required for calculation. GPA is the sum of grade points multiplied by credits, divided by total credits. The package has a build script but no test script; this page does not imply a separate automated test suite.
