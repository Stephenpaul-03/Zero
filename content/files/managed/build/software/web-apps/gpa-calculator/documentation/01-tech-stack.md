# GPA Calculator — Tech stack

## Technical foundation

React, Vite, TypeScript, Tailwind, and Radix-based UI components. Spreadsheet and export dependencies include ExcelJS, SheetJS, jsPDF, and html2canvas.

## Repository map

| Path | Purpose |
| --- | --- |
| src/components/ | Reusable interface components |
| src/hooks/ | Shared state and behavior |
| src/utils/ | Calculation and utility code |
| src/views/ | Application views |
