# Zero

Zero combines the workspace content into one React application. Its homepage leads into Notes, Hardware builds, and Software projects; legal and support pages belong to their Software project while retaining stable direct URLs.

## What it does

- Shared section landing and reading layouts with monochrome surfaces and section accents.
- Notes topic groups, content search, quizzes, outline tracking, and reading progress.
- Software and hardware project collections with ordered Markdown pages.
- Project-level Legal information groups and a separate drag-and-drop content admin.
- Drafts, filesystem saves, and explicit Git commit-and-push publishing from the admin.
