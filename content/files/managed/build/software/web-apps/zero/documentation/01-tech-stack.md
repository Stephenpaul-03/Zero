# Zero — Tech stack

## Technical foundation

React, Vite, TypeScript, Tailwind, and a small Node backend available only in the local admin. The public build excludes filesystem and Git editing endpoints.

## Repository map

| Path | Purpose |
| --- | --- |
| src/ | Public UI, section readers, and local admin components |
| content/ | Content catalog, navigation order, original files, and managed imports |
| server/ | Local filesystem and Git operations |
| shared/ | Markdown rendering and navigation helpers |
| scripts/ | Build preparation, content verification, and page entry generation |
