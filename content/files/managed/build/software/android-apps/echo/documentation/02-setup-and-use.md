# Echo — Setup and use

## Start a session

1. Open Poweramp or another compatible media player and start a track.
2. Open Echo and choose a connection source.
3. Use the artwork area to browse nearby queue items.
4. Reveal controls from the artwork or screen edges.
5. Use the playback and volume actions supported by the session.

## Choose a connection

Use the Poweramp connection when Poweramp is available. The Notification / MediaSession fallback requires Android Notification Access. If the connection fails, confirm that the player is active, the selected source is correct, and the required access remains enabled.

## Permissions and support

Read the original permissions, privacy, and troubleshooting documents under Legal information. Their direct /pages/echo/... URLs remain available for existing app links.

The source checkout is not part of this workspace. No installation or build command is provided without that source.
