# Echo

Echo is a fullscreen Android now-playing companion for Poweramp and compatible media players. It displays artwork, track metadata, playback progress, queue context, and the controls supported by the connected player.

## What it does

- Connects to Poweramp through its supported integration.
- Offers a Notification / MediaSession fallback for compatible players.
- Displays playback context and sends supported control actions to the active session.
- Keeps now-playing processing on the device.
