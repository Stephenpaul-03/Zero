# Tally — Tech stack

## Technical foundation

React Native and Expo with native development builds, SQLite persistence, Redux Toolkit state, and React Native Paper UI. The README specifies Node 22 and JDK 17 plus the Android SDK for Android development.

## Repository map

| Path | Purpose |
| --- | --- |
| modules/Core/ | Persistence, repositories, and shared state |
| modules/Management/ | Transactions, accounts, categories, and budgets |
| modules/Insights/ | Analytics and visual summaries |
| modules/Backup/ | Backup behavior |
| modules/Goals/ and modules/Recurring/ | Goal and recurring-activity features |
| plugins/ and scripts/ | Native configuration and release tooling |
