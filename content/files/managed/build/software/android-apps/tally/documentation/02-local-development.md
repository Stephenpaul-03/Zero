# Tally — Local development

## Local development

Run these commands from the project repository. Commands listed here were inspected, not executed as part of writing this page.

~~~sh
npm ci
npm run check:fonts
npm run android
npm run check:release
~~~

## Project notes

Install the Switzer fonts using the repository font guide before building. Tally needs native modules and does not run in standard Expo Go. The README calls version 0.1.0 an early preview and identifies Android as the current release target; iOS release verification is pending. Build signing and release instructions remain in the source repository docs/android-release.md. No build or signing files were changed for this documentation.
