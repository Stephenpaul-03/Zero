# YOINK Routines

A small command-line tool for defining sequences of shell steps once and running them by name. The package is yoink-routines and the executable is yoink.

## What it does

- Named YAML routines with positional arguments.
- Sequential execution that stops on failure.
- Dry runs, confirmation, timeouts, and verbose output.
- Configuration validation, environment diagnostics, and shell completion commands.
