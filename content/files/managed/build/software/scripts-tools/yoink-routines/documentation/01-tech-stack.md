# YOINK Routines — Tech stack

## Technical foundation

CommonJS Node.js with js-yaml. The package specifies Node 18 or later and uses the built-in Node test runner.

## Repository map

| Path | Purpose |
| --- | --- |
| cli.js | Executable entry point |
| src/ | Routine execution and configuration logic |
| test/ | Automated tests |
| yoink.example.yml | Example routine configuration |
