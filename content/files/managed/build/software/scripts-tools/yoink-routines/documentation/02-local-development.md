# YOINK Routines — Local development

## Local development

Run these commands from the project repository. Commands listed here were inspected, not executed as part of writing this page.

~~~sh
npm install
npm test
npm link
yoink config
yoink list
yoink doctor
~~~

## Project notes

npm link makes the local checkout available as a global command. Preview a routine with --dry-run before running it. Configuration can be selected with YOINK_CONFIG, or stored in the platform-specific application configuration directory. This page documents local usage; it does not install or execute any routines.
