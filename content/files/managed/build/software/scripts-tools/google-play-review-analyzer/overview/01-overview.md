# Google Play Review Analyzer

A local pipeline for turning public Google Play reviews into categorized feedback. An app profile supplies the categories; the pipeline fetches and cleans reviews, classifies them with Ollama, and prepares data for a React dashboard.

## What it does

- App profiles define package IDs, markets, languages, and custom categories.
- Review collection, deduplication, filtering, and model categorization.
- Category summaries, sentiment and complaint fields, and a filterable dashboard.
- Excel export and a single-file dashboard output.
