# AFFiNE.me

This repository is a checkout of AFFiNE, the upstream workspace that combines documents, a canvas, and structured content. It is a monorepo rather than a small standalone web app; the upstream README describes the product, while local development is coordinated through its own CLI.

## What it does

- Block-based documents and an edgeless canvas.
- Web and desktop application packages, with mobile source also present.
- Local-first storage and collaboration infrastructure.
- The BlockSuite editor framework and its reusable blocks.
