# AFFiNE.me — Tech stack

## Technical foundation

TypeScript and React application packages sit alongside Rust native crates. The checkout specifies Node >=22.12 and <23, and Yarn 4.18.0.

## Repository map

| Path | Purpose |
| --- | --- |
| blocksuite/ | Editor framework, blocks, and canvas components |
| packages/frontend/ | Frontend applications and shared UI |
| packages/backend/ | Backend server and native components |
| tools/ | Monorepo development and build tooling |
