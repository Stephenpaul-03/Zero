# Starter Kits — Tech stack

## Technical foundation

The stack varies by folder. Inspect each package.json before installing or running commands; the root has no shared application manifest.

## Repository map

| Path | Purpose |
| --- | --- |
| react-shadcn/ | Web starter; the root README also calls this web-starter |
| native-web/ | React Native and web starter |
| expo-native-web-*/ | Three Expo UI-library variants |
