# Starter Kits

A collection of independent starter folders. Select the relevant folder and use its own manifest and README rather than treating the root as one application.

## What it does

- react-shadcn: React, Vite, TypeScript, Tailwind, and shadcn-style UI.
- native-web: React Native for web, Android, and iOS without Expo.
- expo-native-web-gluestack, expo-native-web-paper, and expo-native-web-tamagui: Expo alternatives with different component libraries.
- node-cli: a small CommonJS command-line starter.
