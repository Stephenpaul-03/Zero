# Portfolio Monograph — Local development

## Local development

Run these commands from the project repository. Commands listed here were inspected, not executed as part of writing this page.

~~~sh
npm install
npm run dev
npm run lint
npm run build
npm run preview
~~~

## Project notes

The repository ships with template identity and example content. Replace those values in src/data/content.json before publishing. A deploy script exists, but deployment is separate from local preview and was not run here.
