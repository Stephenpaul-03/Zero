# Portfolio Monograph

A single-page portfolio template built around a monograph-style presentation of work. It includes personal context and detailed project views while keeping the main content in one JSON file.

## What it does

- Hero, about, journey, selected work, and contact sections.
- Project and discipline detail modals.
- Responsive layouts with light and dark themes.
- Motion and cursor details around the portfolio content.
