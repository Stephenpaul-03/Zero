# Portfolio Doodles

A customizable single-page portfolio with a playful visual language. Its content is kept in a data file so identity, work, and contact details can be adapted separately from the components.

## What it does

- Hero, about, journey, work, hobbies, and contact sections.
- Project and hobby detail modals.
- A draggable hobbies board.
- Responsive light and dark themes and animated details.
