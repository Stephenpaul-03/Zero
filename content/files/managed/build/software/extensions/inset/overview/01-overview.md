# Inset

A VS Code extension that attaches to an already-running Android emulator and places it beside the source code. It also exposes inspection tools for supported React Native development builds.

## What it does

- A shared emulator session in a sidebar or editor tab.
- Touch, scrolling, rotation, Android navigation, typing, and paste.
- Frame streaming and timing diagnostics.
- React Native component picking, a searchable tree, runtime inspection, and source navigation.
