## Project notes

The README labels this pre-v1 development at version 0.3.0, without a Marketplace release or published VSIX. Run it from VS Code with F5, start the emulator separately, then use Inset: Open Emulator. React Native inspection needs a trusted workspace, local Metro, and a compatible Hermes development build. Live emulator use is documented as validated on macOS; Linux and Windows still need live validation. No extension was installed as part of this documentation.
