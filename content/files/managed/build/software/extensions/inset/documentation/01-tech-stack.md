# Inset — Tech stack

## Technical foundation

TypeScript extension code, gRPC emulator transport, WebSocket communication, and a webview interface. The README specifies Node 24 and VS Code 1.95 or later.

## Repository map

| Path | Purpose |
| --- | --- |
| src/discovery/ | Running-emulator discovery |
| src/transport/ | Emulator communication |
| src/inspector/ | React Native inspection |
| src/panel/ | VS Code panel and webview integration |
