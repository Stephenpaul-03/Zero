# Desk environment monitor

> Sample project for previewing Zero. These are example plans, not a completed or tested build.

## The idea

A quiet little display that shows the temperature and humidity beside a workspace. The aim is to make the information readable at a glance without needing an app.

## What it should do

- Read temperature and humidity on a regular interval.
- Show the latest values on a small display.
- Recover from a missing sensor without freezing the interface.
- Fit inside a simple desktop enclosure.

## Project outline

| Part | Purpose |
| --- | --- |
| Microcontroller board | Read measurements and update the display |
| Environmental sensor | Supply temperature and humidity readings |
| Small display | Show values and a last-updated indicator |
| Desktop enclosure | Keep the finished assembly tidy |
