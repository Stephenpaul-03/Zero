# Algorithms

This workspace introduces core searching and sorting algorithms. The goal is not to memorize implementations, but to understand the conditions that make an approach appropriate and the trade-offs it introduces.

## Suggested Path

Start with linear search, then move to binary, jump, interpolation, exponential, and ternary search. For sorting, compare simple quadratic methods with divide-and-conquer and non-comparison approaches.

## What to Compare

For every algorithm, ask:

- What input assumptions does it make—for example, sorted data or a bounded integer range?
- What are the best-case, average-case, and worst-case time costs?
- How much extra space does it use?
- Is it stable, in-place, adaptive, or suitable for streaming data?
- What happens when the input is empty, duplicated, already sorted, or very large?

The notes are reference material. Before using an algorithm in production, test its assumptions against the actual data and workload.
