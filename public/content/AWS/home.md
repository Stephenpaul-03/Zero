# Introduction to AWS

This workspace is an introduction to cloud computing and Amazon Web Services. It starts with the cloud model, then builds toward AWS infrastructure, architecture principles, security, operations, and commonly used services.

## Suggested Learning Path

1. Learn the basic cloud characteristics and service models.
2. Understand AWS Regions, Availability Zones, and the shared responsibility model.
3. Review the Well-Architected Framework and common migration strategies.
4. Use the service notes as focused references while building or designing workloads.

The service notes are intentionally concise starting points. Always confirm production decisions against current AWS documentation, service limits, pricing, and regional availability.
