# Computer Networks

This workspace covers the foundations of computer networking: data transmission, network types and topologies, the OSI and TCP/IP models, addressing, routing, switching, and traffic control. It connects physical communication concepts with the protocols and control mechanisms used by modern networks.

## Suggested Path

1. Begin with transmission, encoding, multiplexing, network devices, and topologies.
2. Use the OSI and TCP/IP notes to understand where protocols operate.
3. Study switching, routing, subnetting, and supernetting to understand packet movement.
4. Finish with flow control, congestion control, admission control, and access control.

## Core Questions

- How is data represented and carried over a medium?
- How does a device decide where to send a frame or packet?
- How are networks divided, addressed, and connected?
- How do protocols handle loss, congestion, speed differences, and security?

The image assets are supporting diagrams; the written notes should remain the source of the definitions and explanations.
