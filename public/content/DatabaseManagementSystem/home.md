# Database Management Systems

This workspace covers database foundations, relational design, query processing, transactions, distributed databases, data warehousing, and NoSQL systems. It moves from the data model to the mechanisms that keep data correct, durable, secure, and efficient.

## Suggested Path

1. Learn database architecture, users, data abstraction, languages, and the relational model.
2. Study keys, constraints, dependencies, normalization, joins, views, and indexing.
3. Continue with storage, query execution, concurrency, recovery, encryption, and deadlocks.
4. Compare replication, sharding, consistency models, data warehousing, and NoSQL models.

## Questions to Keep in Mind

- What data model fits the problem?
- Which constraints protect correctness?
- How will queries be executed and indexed?
- What happens when transactions run concurrently or a node fails?
- Which consistency, availability, and scaling trade-offs are acceptable?
